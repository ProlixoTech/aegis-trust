# AEGIS Trust — Changelog

## 0.1.1 — Documentation and discoverability

- Clarified what AEGIS-managed protection does and does not cover.
- Added an easy first-use guide, a fictional-data practice exercise, real-world use cases, and answers to common questions, with links to the public GitHub documentation.
- Improved the Marketplace extension summary and search keywords.
- Updated bundled security documentation to reflect the public release and avoid outdated pre-release or test-count claims.
- **No changes to executable JavaScript, protection logic, or the trust/ruleset assets compared with the published 0.1.0 VSIX.**

## 0.1.0 — Initial public release

- Initial published Marketplace release of AEGIS Trust, a free, open-source VS Code extension.
- Supported AEGIS-managed workflows include selected local protected-file baselines and snapshots, restore-oriented operations, proposed-command review, and local work receipts.
- This release is not a universal AI sandbox, malware defense, or substitute for independent backups.
